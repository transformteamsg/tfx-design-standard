  deliberately light-only (`app/globals.css:4-6` comment). Documenting

  `app/globals.css`; the spacing-radius page defers elevation to shadcn
  defaults. Adding the tokens first is a standards decision, not a docs task.
- *Interactive copy-to-clipboard buttons on token rows*: nice-to-have; adds
  client JS to otherwise-server pages. Deferred — token names render in
  `<code>` and are selectable. Revisit after the pages exist.
