## Why this matters

On 2026-07-06 the design lead committed five new controls to the catalog (plans
053/057): **LAY-1** (declared column grid), **LAY-7** (single focal region /
reading order matches task priority), **IDN-2** (product icons from the approved

casework sensitivity — the first `products:`-scoped control). The catalog now

But **no skill or agent references any of the five**. A repo-wide grep of
`harness/.claude/` finds zero occurrences of `IDN-` and `LAY-7`, and the only
`LAY-1` mention says it hasn't landed yet. Worse, three surfaces actively state

controls … Grid systems remain HIG + judgment until a declared product grid
lands", and the layout pass says "a declared product grid is not yet a checkable
control". The evaluator grades judgment controls — IDN-3, IDN-4, and LAY-7 are
judgment controls in `phase: verify` that it will silently never grade. A page
graded "clean" today is unverified against the catalog's five newest rules.
